# Ensambles de carpintería · Dossier

21 ensambles de carpintería en 3D para ciclos formativos de madera, mueble y corcho: cómo se montan, cómo se hacen a mano paso a paso (marcar, serrar, vaciar y montar con herramientas de mano), errores típicos, láminas acotadas, cuaderno de prácticas y apuntes.

**Web:** https://eloiaa-hub.github.io/Ensambles-Dossier/

| Archivo | Qué es |
|---|---|
| [`index.html`](index.html) | Página de inicio con los 21 ensambles |
| [`ensambles_3d_alumno.html`](ensambles_3d_alumno.html) | Versión del alumnado (adaptada al móvil) |
| [`ensambles_3d.html`](ensambles_3d.html) | Versión del profesor: medidas, láminas, cuaderno, DXF, evaluación, QR y vídeo |
| [`apuntes_ensambles_a_mano.html`](apuntes_ensambles_a_mano.html) · [PDF](apuntes_ensambles_a_mano.pdf) | Apuntes: los 21 ensambles hechos a mano, paso a paso |
| [`manual_ensambles.html`](manual_ensambles.html) · [PDF](manual_ensambles.pdf) | Manual de uso |
| `modelos/` | Modelos 3D de las herramientas (GLB) |

**En el móvil, sin conexión:** abre la web y pulsa «📲 Instalar» (Android) o *Compartir → Añadir a pantalla de inicio* (iPhone). Con abrirla una vez con conexión, después funciona en el taller sin internet.

También funciona sin instalar nada y sin internet: descarga el repositorio (**Code → Download ZIP**) y abre los HTML con doble clic, manteniendo la carpeta `modelos` junto a los programas.

Enlaces directos a un ensamble: `ensambles_3d_alumno.html#mmT`, `#mmT/manual`, `#mmT/manual/5`, `#mmT/errores` (también vale el número: `#18`).
